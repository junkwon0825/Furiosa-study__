# 01. Foundations

## 학습 내용

Python 함수와 lambda, module/package import 구조, Pandas 기반 데이터 선택 및 결측치 전처리를 실습했습니다.

## 핵심 개념

- `map`, lambda, 함수 호출
- module과 package import
- Pandas `loc` / `iloc`
- 결측치 보간과 interpolation
- `SimpleImputer`, `KNNImputer`, `IterativeImputer`

## 폴더

| 경로 | 내용 |
|---|---|
| `python_basics/` | 함수형 표현과 lambda 기초 |
| `modules_packages/` | module/package 정의와 import 방식 |
| `data_preprocessing/` | Pandas indexing, 결측치 탐색과 imputation |

단순 예제도 이후 ML/DL 코드에서 사용한 Python 문법과 전처리의 출발점이므로 작은 학습 단위로 보존했습니다.
